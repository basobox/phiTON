## 🏛️ PART 1: The 4 ELMN Framework (Pondasi Utama)

Di dunia Data Science, **80% waktu habis untuk menyiapkan data**. Jika fondasi 4 poin dasar ini rapuh, kandidat akan gagal di tahap industri. 4 ELMN ini adalah pilar kesiapan kerja Anda:

* **E - Execution (Python Core & Logic)**
  * *Fokus:* Pembuatan fungsi (`def`), logika *looping*, alur kontrol data, serta pemahaman parameter dan nilai pengembalian (`return`).
* **L - Link (SQL & Relational Database)**
  * *Fokus:* Menghubungkan Python ke database server (PostgreSQL/pgAdmin 4). Mahir kueri data tingkat menengah (`SELECT`, `WHERE`, `JOIN`, `GROUP BY`).
* **M - Manipulation (Pandas & Data Wrangling)**
  * *Fokus:* Kilang pengolahan data kotor. Menangani *missing values* (`.fillna()`, `.dropna()`), *filtering*, *grouping*, dan optimasi transfer data besar menggunakan parameter `chunksize` pada `.to_sql()`.
* **N - Nexus (Architectural OOP)**
  * *Fokus:* Memahami cetak biru (*Class* dan *Object*), penggunaan variabel `self`, dan logika *passing parameter* dalam arsitektur OOP untuk membaca library pihak ketiga (seperti *Scikit-Learn* atau *TensorFlow*).

## 🛠️ PART 5: Strategi Portofolio GitHub (Storytelling Bisnis)
Jangan menamai tugas dengan nama akademis. Ubah cara menulis file `README.md` repositori Anda menjadi berorientasi proyek klien:
1. **Judul:** Fokus pada solusi bisnis (Contoh: *Automated Bikeshare Data Wrangling Pipeline*).
2. **The Problem:** Narasikan masalah data kotor atau *crash* memori database yang dihadapi perusahaan fiktif/nyata.
3. **The Solution:** Tunjukkan potongan kode optimasi Anda (misal: penanganan *missing values* dengan Pandas atau parameter `chunksize` pada SQL).
4. **Business Impact:** Tuliskan dampak efisiensi waktu setelah menggunakan skrip otomatisasi Anda.
